# Beautiful UI

MediX's Vue UI adapts the design tokens and component patterns from
https://github.com/slev12397/beautiful-ui (commit 44a274e598395ab61e7c96c26fda2758780253b7).
Source patterns: SidebarNav, PromptBar, ThinkingState, RecordsTable and ContextCards.
The implementation uses native Vue 3 components and plain CSS equivalents of the
upstream tokens. Demo sequences/data and commercial Central Icons are not included.
